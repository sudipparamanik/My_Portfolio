# Sudip Paramanik — AWS Cloud Engineer Portfolio

A modern React + TypeScript + Vite + Tailwind CSS portfolio featuring:

- Profile photo with click-to-enlarge modal
- AWS/cloud-focused hero section
- Projects and technology stack
- IBM SkillsBuild / Edunet Foundation internship experience
- Certificate gallery with image previews and original PDF links
- Responsive navigation and mobile menu
- Framer Motion animations

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Main folders

- `src/App.tsx` — page layout and components
- `src/data/portfolio.ts` — portfolio content
- `public/images/profile.png` — profile photo
- `public/certificates/` — certificate PDFs and preview thumbnails
